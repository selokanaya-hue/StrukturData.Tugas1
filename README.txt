Penjelasan lengkap mengenai kegunaan dan cara pengerjaan dari ketiga project tugas Struktur Data (Pertemuan 2 - Universitas Pelita Bangsa dengan dosen pengampu Anggi Alfin, S.Kom., M.Sc.).   

1. Project 1: Data Nilai Mahasiswa (Array 1D)

Kegunaan / Tujuan:
Program ini berguna untuk menerapkan konsep Array 1 Dimensi (menggunakan list di Python) guna mengelola dan mengorganisasi data nilai akademik mahasiswa secara terstruktur melalui sistem menu interaktif berbasis konsol di Visual Studio Code.   

Cara Pengerjaan & Fitur Utama:

Input Data: Pengguna memasukkan jumlah mahasiswa (maksimal 10 orang), diikuti dengan input nama dan nilai masing-masing mahasiswa. Data tersebut disimpan ke dalam dua array 1 dimensi terpisah (daftar_nama dan daftar_nilai).   

Tampilkan Data: Menampilkan seluruh data mahasiswa yang tersimpan dalam bentuk daftar bernomor yang rapi.   

Analisis Data: Program secara otomatis dapat mencari nilai tertinggi, nilai terendah, serta menghitung rata-rata nilai kelas.   

Ubah & Hapus Data: Pengguna dapat memperbarui atau menghapus data mahasiswa tertentu berdasarkan nomor index ataupun berdasarkan nama mahasiswanya.   

2. Project 2: Data Mahasiswa 2D (Array 2D)

Kegunaan / Tujuan:
Program ini bertujuan untuk menerapkan konsep Array 2 Dimensi (matriks / list di dalam list di Python) guna menyimpan sekumpulan data yang lebih kompleks, yaitu nilai dari beberapa mahasiswa untuk beberapa mata kuliah sekaligus, lalu menyajikannya dalam bentuk tabel.   

Cara Pengerjaan & Fitur Utama:

Input Data Multi-Dimensi: Pengguna memasukkan jumlah mahasiswa (maks. 10) dan jumlah mata kuliah (maks. 5), beserta nama-nama mata kuliahnya.   

Pengisian Nilai Matrix: Program meminta input nilai untuk setiap mata kuliah pada tiap mahasiswa, yang kemudian disusun ke dalam struktur array 2 dimensi (nilai_2d[baris][kolom]).   

Tabel & Rata-rata: Program menampilkan output dalam bentuk tabel yang menyelaraskan nama mahasiswa, nilai setiap mata kuliah, serta hasil kalkulasi rata-rata nilai per mahasiswa secara otomatis.   

Analisis Kolom: Program melakukan pencarian nilai tertinggi dan terendah untuk masing-masing mata kuliah dengan cara membaca data secara vertikal (per kolom pada array 2D).   

3. Project 3: Manajemen Data Barang (Array 1D)

Kegunaan / Tujuan:

Program ini dirancang untuk mengelola inventaris atau data barang menggunakan Array 1 Dimensi, serta menerapkan logika dasar algoritma pencarian (searching) dan pengurutan (sorting) dalam sebuah aplikasi berbasis menu console.   

Cara Pengerjaan & Fitur Utama:

Input Data Inventaris: Pengguna dapat memasukkan data barang baru (maksimal 20 barang) yang mencakup nama barang dan harganya ke dalam array 1 dimensi yang paralel.   

Tampilkan Data: Menampilkan daftar seluruh barang lengkap dengan nomor urut dan format harga mata uang.   

Cari Barang: Fitur pencarian memungkinkan pengguna melacak keberadaan barang tertentu berdasarkan kata kunci nama barang yang diinputkan.   

Urutkan Harga (Sorting): Menerapkan algoritma pengurutan sederhana (seperti Bubble Sort) untuk mengurutkan harga barang secara ascending (dari yang termurah hingga termahal) beserta penyesuaian posisi namanya agar tetap sinkron.   

Hapus Data: Memungkinkan pengguna menghapus inventaris barang berdasarkan nomor index data di dalam sistem.
